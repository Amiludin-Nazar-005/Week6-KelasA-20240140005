# Week 5 Revision

Tugas Fetch API (etalase produk) dan Form DOM & Event Handling (generator caption).

## Struktur Folder

```
week5-revision/
├── public/
│   ├── index.html      # halaman Etalase
│   ├── form.html       # halaman Caption
│   ├── css/
│   │   ├── index.css   # style utama, dipakai kedua halaman
│   │   └── form.css    # style khusus form (dimuat setelah index.css)
│   └── js/
│       ├── index.js    # fetch, cari, dan filter produk
│       └── form.js     # template caption dan validasi
├── latihan/
│   └── fetch.js        # script uji coba fetch API
└── README.md
```

## Cara Menjalankan

Buka `public/index.html` di browser, atau gunakan ekstensi Live Server di VS Code. Perlu koneksi internet untuk mengambil data dari https://dummyjson.com/products.
